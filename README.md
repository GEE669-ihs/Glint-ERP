# Glint ERP (HTML + CSS + JavaScript)

Buka `index.html` di browser (Chrome/Edge/Firefox). Tanpa instalasi dan tanpa server.

Modul: Dashboard, Penjualan, Produksi, Inventori, Keuangan, Pelanggan, Laporan, Pengaturan.
Data tersimpan di localStorage browser. Buat cadangan lewat menu Laporan.

Data awal = kondisi nyata: modal Rp77.792 (microfiber 6, IPA 250 ml, aquadest 1 L, botol 4, label 41, spuit),
resep per botol: IPA 25 ml + aquadest 25 ml + botol + microfiber + 2 stiker. Harga Rp19.000 / Duo Rp35.000 / Trio Rp50.000.
Untuk mencoba semua fitur: Pengaturan > Muat data demo.
